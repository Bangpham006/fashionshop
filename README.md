# Fashion Shop Website

A full-stack e-commerce fashion website that allows users to browse products, manage shopping carts, and place orders online.

## Features

### Frontend
- Responsive user interface
- Product listing and filtering
- Product detail pages
- Shopping cart functionality
- User authentication
- PayPal payment integration
- Order management UI

### Backend
- RESTful API development
- User authentication and authorization
- Product and category management
- Order processing
- Database integration

## Technologies Used

### Frontend
- React.js
- TypeScript / JavaScript
- Axios
- React Router
- Lucide React

### Backend
- Node.js
- Java SpringBoot
- MongoDB 
- JWT Authentication

## Installation

### Clone Repository

```bash
git clone https://github.com/your-username/fashion-shop.git
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Backend Setup

```bash
cd backend
npm install
npm start
```

## Environment Variables

Create a `.env` file inside the backend folder and add:

```env
PORT=5000
MONGO_URI=your_database_url
JWT_SECRET=your_secret_key
```
