# Fashion Shop Website

A full-stack e-commerce fashion website that allows users to browse products, manage shopping carts, and place orders online.

## Features

### Frontend
- Responsive user interface
- Product listing and filtering
- Product detail pages
- Shopping cart functionality
- User authentication
- PayPal payment integration
- Order management UI

### Backend
- RESTful API development
- User authentication and authorization
- Product and category management
- Order processing
- Database integration

## Technologies Used

### Frontend
- React.js
- TypeScript / JavaScript
- Axios
- React Router
- Lucide React

### Backend
- Node.js
- Java SpringBoot
- MongoDB 
- JWT Authentication
